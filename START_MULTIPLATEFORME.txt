🚀 TU AS 3 APPLICATIONS À CRÉER (ou plus!)

┌─────────────────────────────────────────────────────────────────────────────┐
│ 🌐 PWA (Web Installable) - DÉMARRER MAINTENANT                              │
├─────────────────────────────────────────────────────────────────────────────┤
│ Installation : 0 (ça marche directement)                                    │
│ Plateformes  : Windows, macOS, Linux, Android, iOS                          │
│ Temps build  : 2-5 minutes                                                  │
│ App Store    : Non (web seulement)                                          │
│ Offline      : ✅ Oui                                                        │
│ Notifications: ✅ Oui (Web Push)                                             │
└─────────────────────────────────────────────────────────────────────────────┘

COMMANDES PWA :

1️⃣  Accède au dossier
    cd ctc-sante-app

2️⃣  Copie la config PWA
    cp ../next.config.pwa.js ./next.config.js

3️⃣  Installe next-pwa
    npm install next-pwa

4️⃣  Lance le serveur
    npm run dev

5️⃣  Ouvre dans le navigateur
    http://localhost:3000

6️⃣  Clique "Installer l'app" (coin haut droit du navigateur)
    → L'app s'installe comme une app native! 🎉

COMMANDES REACT NATIVE :

1️⃣  Crée compte Expo
    https://expo.dev/signup

2️⃣  Installe Expo CLI
    npm install -g eas-cli

3️⃣  Accède au dossier
    cd ctc-sante-mobile

4️⃣  Installe les dépendances
    npm install

5️⃣  Initialise Expo
    eas build:configure

6️⃣  Lance localement (dev)
    npm start

7️⃣  Teste sur Android
    npm run android

8️⃣  Teste sur iOS (Mac seulement)
    npm run ios

9️⃣  Build pour Play Store / App Store
    eas build --platform android
    eas build --platform ios


┌─────────────────────────────────────────────────────────────────────────────┐
│ 🖥️  ELECTRON (Windows/Mac/Linux Desktop) - SEMAINE 2                        │
├─────────────────────────────────────────────────────────────────────────────┤
│ Installation : 20 min                                                       │
│ Plateformes  : Windows, macOS, Linux                                        │
│ Temps build  : 10-15 min                                                    │
│ App Store    : Oui (Windows/Mac/Linux respectifs)                           │
│ Offline      : ✅ Oui (SQLite local)                                         │
│ Notifications: ✅ Oui (Native)                                               │
│ Avantage     : Database locale, accès fichiers                              │
└─────────────────────────────────────────────────────────────────────────────┘

COMMANDES ELECTRON :

1️⃣  Accède au dossier
    cd ctc-sante-desktop

2️⃣  Installe les dépendances
    npm install

3️⃣  Lance en dev
    npm run electron-dev

4️⃣  Build Windows (.exe)
    npm run electron-build-win
    → Fichier : dist/CTC Santé Setup 1.0.0.exe

5️⃣  Build macOS (.dmg)
    npm run electron-build-mac
    → Fichier : dist/CTC Santé-1.0.0.dmg

6️⃣  Build Linux (.AppImage / .deb)
    npm run electron-build-linux
    → Fichiers : dist/CTC Santé-1.0.0.AppImage
                  dist/ctc-sante-desktop_1.0.0_amd64.deb

✅ Tokens stockés de manière sécurisée :
   - PWA      : Service Worker + localStorage (HTTPS)
   - React    : Expo.SecureStore (chiffré)
   - Electron : keytar + SQLite (chiffré)

✅ Données chiffrées en transit (HTTPS/TLS)

✅ Authentification JWT valide 24h

✅ Base de données locale pour offline-first

✅ No hardcoded secrets
