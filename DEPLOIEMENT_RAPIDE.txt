═══════════════════════════════════════════════════════════════════════════════

ÉTAPE 1: Installer Expo Go sur votre téléphone (gratuit)
  → App Store (iPhone)
  → Google Play (Android)

ÉTAPE 2: Lancer l'app (copier-coller):

cd ctc-sante-mobile && npm install && npm start

ÉTAPE 3: Scanner le QR code avec votre téléphone

═══════════════════════════════════════════════════════════════════════════════
🟢 OPTION 2 - BUILD ANDROID APK (5-7 minutes)
═══════════════════════════════════════════════════════════════════════════════

✓ Crée un fichier .apk que vous pouvez partager par email/WhatsApp/Drive

COMMANDE COMPLÈTE (copier-coller):

cd ctc-sante-mobile && \
npm install && \
eas build:configure && \
eas build --platform android

APRÈS LE BUILD:
  • Un lien s'affiche pour télécharger le fichier .apk
  • Téléchargez le fichier
  • Transférez-le sur votre téléphone Android
  • Installer l'application (Autoriser installation depuis sources inconnues)
  • Ouvrir CTC Santé

PARTAGER L'APK:
  • Le fichier .apk est distribuable
  • Peut être envoyé par email
  • Peut être partagé sur Google Drive/WhatsApp

═══════════════════════════════════════════════════════════════════════════════
🔵 OPTION 3 - BUILD iOS IPA (10-15 minutes)
═══════════════════════════════════════════════════════════════════════════════

⚠️ PRÉREQUIS: Compte Apple Developer ($99/an)

COMMANDE COMPLÈTE (copier-coller):

cd ctc-sante-mobile && \
npm install && \
eas build:configure && \
eas build --platform ios

APRÈS LE BUILD:
  • Un lien s'affiche pour télécharger le fichier .ipa
  • Utiliser Testflight (recommandé)
  • OU transférer via Xcode Application Loader

═══════════════════════════════════════════════════════════════════════════════
🟡 OPTION 4 - PWA (WEB) - 3 minutes
═══════════════════════════════════════════════════════════════════════════════

✓ Application web progressive - Fonctionne dans n'importe quel navigateur
✓ Peut être installée comme app (Accueil + mode fullscreen)
✓ Fonctionne hors ligne

DÉVELOPPEMENT LOCAL (copier-coller):

cd ctc-sante-pwa && \
npm install && \
npm run dev

PUIS:
  • Ouvrez: http://localhost:3000 dans votre navigateur
  • Testez l'application
  • Installez-la comme app web (menu navigateur: Installer app)

BUILD PRODUCTION (prêt pour déploiement):

cd ctc-sante-pwa && \
npm install && \
npm run build

DÉPLOYER SUR VERCEL (gratuit):
  1. Créer compte: https://vercel.com
  2. npm i -g vercel
  3. cd ctc-sante-pwa && vercel --prod

═══════════════════════════════════════════════════════════════════════════════
🟠 OPTION 5 - ELECTRON (DESKTOP) - 2-3 minutes
═══════════════════════════════════════════════════════════════════════════════

✓ Application native Windows/Mac/Linux
✓ Base de données locale SQLite
✓ Stockage sécurisé credentials (Keytar)

DÉVELOPPEMENT LOCAL (copier-coller):

cd ctc-sante-desktop && \
npm install && \
npm run electron-dev

APRÈS:
  • L'application desktop se lance
  • Testez la fonctionnalité locale
  • Données sauvegardées dans SQLite local

BUILD POUR DISTRIBUTION:

# Windows (.exe, .msi)
cd ctc-sante-desktop && npm run electron-build-win

# macOS (.dmg, .pkg)
cd ctc-sante-desktop && npm run electron-build-mac

# Linux (.AppImage, .deb)
cd ctc-sante-desktop && npm run electron-build-linux

FICHIERS GÉNÉRÉS dans: ctc-sante-desktop/dist/

🆘 DÉPANNAGE RAPIDE
═══════════════════════════════════════════════════════════════════════════════

❌ "npm: commande introuvable"
   → Installer Node.js: https://nodejs.org

❌ "Port déjà utilisé"
   → npm start -- --port 8082

❌ "Cannot connect to metro bundler"
   → Fermer tout et relancer: npm start

❌ "EAS CLI introuvable"
   → npm install -g eas-cli

❌ Erreur lors du build
   → Supprimer node_modules: rm -rf node_modules
   → Réinstaller: npm install --legacy-peer-deps
