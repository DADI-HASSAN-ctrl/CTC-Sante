🟢 OPTION 2 : BUILD ANDROID (5-7 minutes) - FICHIER .APK TÉLÉCHARGEABLE
═══════════════════════════════════════════════════════════════════════════════

✅ Crée un fichier .apk que vous pouvez distribuer et installer sur n'importe quel Android

ÉTAPE 1 : Configuration EAS (première fois uniquement)
   cd ctc-sante-mobile
   eas build:configure

   Sélectionner :
   ✓ Android: managed
   ✓ iOS: managed (si vous avez un compte Apple)

ÉTAPE 2 : Lancer le build
   eas build --platform android

   → Attend < 5 minutes
   → Affiche lien de téléchargement .apk
   → Télécharger et installer sur téléphone

ÉTAPE 3 : Tester l'application
   Installer le fichier .apk
   Ouvrir l'app CTC Santé
   Utiliser comptes de test ci-dessus

📊 Fichier .apk peut être partagé par email/WhatsApp/Drive

═══════════════════════════════════════════════════════════════════════════════
🔵 OPTION 3 : BUILD iOS (10-15 minutes) - FICHIER .IPA POUR IPHONE
═══════════════════════════════════════════════════════════════════════════════

⚠️ PRÉREQUIS : Compte Apple Developer ($99/an)

ÉTAPE 1 : Configuration (première fois)
   cd ctc-sante-mobile
   eas build:configure
   → Sélectionner iOS: managed

ÉTAPE 2 : Lancer le build
   eas build --platform ios

   → Attend < 10 minutes
   → Crée fichier .ipa

ÉTAPE 3 : Installer sur iPhone
   Utiliser Apple Testflight OU installer directement via:
   - Transférer fichier .ipa via iCloud/iTunes
   - Utiliser Application Loader (Xcode)

🟡 OPTION 4 : SIMULATEUR LOCAL (3-5 minutes) - DÉVELOPPEMENT RAPIDE

✅ Simulateur iOS sur Mac OU Émulateur Android sur n'importe quel OS

   1. Installer Android Studio: https://developer.android.com/studio
   2. Créer un émulateur virtuel (5 min)

   2. Lancer :

🆘 DÉPANNAGE RAPIDE
═══════════════════════════════════════════════════════════════════════════════

❌ "npm: commande non trouvée"
   → Installer Node.js depuis https://nodejs.org

❌ "EAS CLI not found"
   → npm install -g eas-cli

❌ "Port 8081 déjà utilisé"
   → npm start -- --port 8082

❌ "Cannot connect to metro bundler"
   → Fermer tout, redémarrer: npm start

❌ Erreur sur emulateur Android
   → Relancer emulateur depuis Android Studio
   → npm start
   → Appuyer 'a'
