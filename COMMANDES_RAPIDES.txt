🟢 OPTION 2 : DÉPLOIEMENT DOCKER (Production-ready)
────────────────────────────────────────────────────

PRÉREQUIS : Avoir Docker installé
  Télécharge ici → https://www.docker.com/products/docker-desktop

COMMANDES À COPIER/COLLER :

1️⃣  Accède au dossier
    cd ctc-sante-app

2️⃣  Lance l'application (première fois = 5-10 min, après = 30 sec)
    docker compose up --build

3️⃣  ✅ Ouvre dans le navigateur
    http://localhost:3000

4️⃣  Pour arrêter
    docker compose down

5️⃣  Pour voir les logs
    docker compose logs -f

🟡 OPTION 3 : NPM (Si Docker ne fonctionne pas)
──────────────────────────────────────────────

PRÉREQUIS :
  • Node.js 18+ → https://nodejs.org
  • PostgreSQL 14+ → https://www.postgresql.org/download

COMMANDES À COPIER/COLLER :

1️⃣  Accède au dossier
    cd ctc-sante-app

2️⃣  Installe les paquets
    npm install

3️⃣  Configure la base de données
    • Lance PostgreSQL (voir guide complet pour détails)
    • Crée la base : createdb ctc_sante -U postgres
    • Édite .env.local avec ton mot de passe

4️⃣  Initialise la base de données
    npm run db:push
    npm run db:seed

5️⃣  Lance l'appli
    npm run dev

6️⃣  ✅ Ouvre dans le navigateur
    http://localhost:3000
